TRANSITION TRADE SYSTEM

OHLC・BB・3MACD・MAなどを組み合わせ、相場の方向とトリガーを確認するためのシステムです。

システム構成

5 FEATURES
01 / MARKET DATA

OHLC分析

始値・高値・安値・終値から、ローソク足の方向性と値動きの状態を確認します。

02 / VOLATILITY

ボリンジャーバンド（BB）

複数期間のバンド幅と価格位置を見て、バンドウォークや相場の変化を捉えます。

03 / TREND

移動平均線（MA）

短期・中期・長期の移動平均線を比較し、トレンドの向きと位置関係を確認します。

04 / MOMENTUM

3MACD

短期・中期・長期のMACDを重ね、勢いの変化と方向感を多角的に判断します。

05 / SIGNAL

トリガー表示・総合判定

各指標の条件をまとめ、売買を検討するタイミングと相場状況を見やすく表示します。
